# BE / LLA / KO — Demo

Catálogo estático en español para presentar la tienda. 24 productos, fotos locales, filtros, tallas, bolsa y mensaje por WhatsApp. El logotipo se conserva como la imagen proporcionada, con BE / LLA / KO en tres líneas.

El panel `admin/` es una demostración local sin autenticación: sus cambios solo se guardan en este navegador y se pueden restablecer. No subir datos privados ni contraseñas. GitHub Pages no ejecuta el servidor PHP/MySQL original. Los pedidos de esta demo no reciben número persistente ni descuentan inventario.

## Publicación
En GitHub → Settings → Pages → Deploy from a branch → main → / (root). No requiere compilación.

Fotos y datos de ejemplo. Las imágenes de productos son referencias de Unsplash y no representan el inventario real. El logo pertenece a la tienda.
